# PiLauncher

Touch launcher for a Raspberry Pi with a 3.5" SPI screen (ILI9486 + ADS7846 touch). It draws directly to
`/dev/fb0`, reads the touch panel without a desktop environment and starts at boot.

This folder is what each release contains and what runs on the Pi from `/opt/pilauncher/current`.
See the [main README](../README.md) for installation, the apps, over-the-air updates and how to write an app.
